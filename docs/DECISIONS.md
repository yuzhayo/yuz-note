## 2026-09-15 — P1

1. Generator = `Visual Studio 18 2026` (bundled CMake 4.3.1 lists it natively).
   Rejected: NMake fallback (kept as fallback only, per PLAN §2).
2. Velopack 1.2.0 lockstep (latest stable 2026-06-03; same pin as Citadel's `vpk`).
   ZIP resmi dan file hasil extract diverifikasi `Restore-Dependencies.ps1` sebelum configure.
3. Restore hanya win-x64 dynamic (headers + `.dll` + `.dll.lib`); linux/osx/arm/x86
   dan static libs tidak disimpan di source tree.
4. Assoc helper = raw WinAPI, no Qt (hooks run pre-`QApplication` in the 30 s
   critical window; zero QSettings-registry ambiguity).
5. Hook signature `void(void*, const char*)` read from restored `Velopack.h:197`
   (`vpkc_hook_callback_t`) — the PLAN snippet is valid only with this signature.
6. MSVC `/utf-8` added (UTF-8 sources; Velopack strings are UTF-8 by contract).
7. Entry point: plain `add_executable(WIN32)` + `Qt6::Widgets` (Qt6 pulls
   `EntryPointPrivate` transitively — no `qtmain`/`Qt6::EntryPoint` target in 6.8.3).
   Fallback `qt_add_executable` only if the link complains.
8. UpdateManager C++ surface confirmed in header (`optional<UpdateInfo>`,
   C-callback trampoline needed for progress, `WaitExitThenApplyUpdates` + self
   `exit(0)`) — design input P4, no code yet.

## 2026-09-15 — P2

9. cmark-gfm 0.29.0.gfm.13 (latest stable; tarball SHA-256 pinned in
   `cmake/FetchCmarkGfm.cmake`). Verified targets `libcmark-gfm_static` +
   `libcmark-gfm-extensions_static` and options `CMARK_TESTS/SHARED/STATIC`
   from the extracted tree before writing a line.
10. FetchContent + `CMAKE_POLICY_VERSION_MINIMUM 3.5` (their min is 3.0, CMake is
    4.3 — the official bridge, no source patching). Documented fallback (unused):
    direct-compile the ~30 C files with a hand-written `config.h`.
11. `CMARK_OPT_UNSAFE` + `tagfilter` extension (Telegram's exact combo): raw HTML
    must survive so our stages see `<details>`/`<img>`; dangerous tags are filtered
    by tagfilter. Static link + `CMARK_GFM_STATIC_DEFINE`.
12. `<details>` handled at SOURCE level pre-split (not HTML post-process): blank
    lines inside a block cannot tear it apart; mirrors the snapshot's recursive
    body re-parse. Fence-aware scan; nested flattened + warning; unclosed and
    summary-less left as-is + warning; recursion capped at 8.
13. `<img>` sanitize at HTML-string level, quote-aware; unclosed tag also replaced
    (deterministic for the gate: output never contains `<img`).
14. Math is passthrough in P2 (cmark has no math; `$` stays literal). MicroTeX = v2.
15. Binary fixtures generated by `run-corpus.ps1` (committed corpus stays text-only);
    `>4MiB` generated at gate time, never committed. `file_size` pre-check guards
    mdparse against OOM before reading.
16. mdparse exit codes 0/1/2/3 (ok / unreadable-validate / render / usage).
17. cmark-gfm 0.29 `cmark_render_html` takes 3 args (root, options, extensions
    list) — built via `cmark_llist_append` + `cmark_get_default_mem_allocator`
    (verified in vendored header, not assumed). First build caught by compiler.
18. C4310 on BOM byte casts → replaced with unsigned byte-reader `BomEquals`
    (no narrowing casts anywhere on the validate path).
19. Root `CMAKE_AUTOMOC ON` scoped OFF around cmark FetchContent (pure-C target;
    kills dev-warning noise; restored after).

## 2026-09-15 — P3

20. `open` attribute: parsed at P2 (standalone word, case-insensitive) → ▾+visible;
    absent → ▸ + viewer hides at load. Marker char doubles as the state signal
    (no extra channel between P2 output and viewer).
21. Table borders + code language labels injected in VIEWER pre-process, not P2
    (presentation belongs to the viewer; P2 output stays semantic). Label as a
    separate paragraph above the block, so P4 copy-code copies pure code only.
22. Sentinel block hidden permanently (metadata, zero-height); body toggled;
    summary is real content. Anchor discovery via fragment `anchorName()` walk.
23. Cursor override via `mouseMoveEvent` + `cursorForPosition` (deterministic hand;
    no reliance on the `openLinks`-hover default).
24. `loadResource` deny-all = defense in depth (sanitizer already strips `<img>`).
25. Undo disabled (programmatic marker edits must not pollute the undo stack).
26. Scripted gate = offscreen `viewer-smoke` tool (no eyes available); visual parity
    checklist left for explicit user sign-off, not assumed.
27. `argv[1]` direct-load scaffolding in `main` (P4 formalizes CLI parsing).
28. Theme hexes = Telegram-dark approximations (exact values unknowable offline;
    tuned at the visual gate).
29. Smoke expectation inverted on first run (asserted hide-first on a block that
    starts collapsed — app was right, test was wrong). Fixed by asserting BOTH
    initial states and BOTH toggle directions (details-edge closed-start,
    details.md `open`-start). Lesson: stateful UI needs direction-aware asserts.
